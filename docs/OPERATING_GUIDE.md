# Career Radar: controlled daily use

Use Evidence matching to review your evidence profile, then Live vacancies for real source listings. The landing dashboard contains clearly marked illustrative demo cards; those are not current vacancies or engine outputs. Fit Calibration provides the full requirement/evidence table with its own visible salary and contract controls. Set these controls before evaluating a role.

Apply, Apply with tailoring, Investigate, Not assessable and Skip are advisory triage. Missing statements are unknown, not inability. You make the final Apply / Skip / Investigate choice. These buttons record a browser-local review only; no application is sent. Review records do not automatically retrain the engine. Use the original source link to verify availability and requirements before applying.

Unknown or small employers receive no penalty. Limited intelligence is enabled by default in Fit Calibration and can be switched off per evaluation. It provides dated official-source employer descriptions (initially Elysium Healthcare and gategroup), questions triggered by advert text, and up to three distinct sourced comparisons from the latest search. It does not run automatic web searches, assess employer quality, or change fit scores/recommendations. Unknown employers receive no penalty. Source links, dates, excerpts and SHA-256 fingerprints are available in provenance details. Provider summaries remain labelled summaries. Personal-profile fine tuning, two-track commute automation and broader research coverage are later work. Both search and calibration must use the intended salary/contract settings; there is no automatic London/local preference migration in this release.

Development runs `npm test`, `npm run simulate` (22-source synthetic run), and `npm run build`. `npm run dev` is a local mocked QA server: it does not call Adzuna/OpenAI and is not the production server. Hosting uses the built Worker in dist/server/index.js.

The deterministic core does not send CV text to an external model. The inherited Semantic AI tab is a separate opt-in workflow and may require paid API consent/configuration; it was not exercised by this release. Personal data stays outside tests.

## Search-summary correction (5.4.2)

Adzuna search excerpts are explicitly marked summaries and receive no numeric fit score. Use Original listing to verify the vacancy. Assess full advert opens Fit Calibration and carries the selected title/source and your current search salary floor. Paste the full original text including criteria, check the completeness box, then Evaluate evidence. This is an explicit user attestation, not automatic source certification.

Headline/self-description CV lines are not demonstrated work evidence. Supporting a management team does not establish line management. A temporary 3–4 week initial contract does not meet the six-month floor, regardless of a possible extension. Research-panel participation listings are excluded from employment triage. Indexed salary ranges and estimated flags must be checked against original pay/hours; estimates cannot prove eligibility.

## Decision clarity (5.4.5)

An unknown configured contract-duration, salary or location check now produces Investigate before an application recommendation. A missing closing date alone keeps confidence Low and adds a source-verification action. Insufficient advert evidence still takes precedence as Not assessable; blocked eligibility remains Skip. Expected role-family categories are named and explicitly described as extraction-coverage checks, not candidate deficits or invented published essentials. Tailoring examples cite only existing profile evidence and the matching advert duty. Limited intelligence needs no extra action: leave Include limited intelligence checked, supply the original advert and employer, and Evaluate evidence. An optional original vacancy URL provides a link for a manually pasted advert. The old duplicate Priority and disabled contextual-score panels have been replaced by the explanatory intelligence section.

## Source accounting (5.4.6)

Fit Calibration retains unknown published duties and criteria as manual-review entries rather than dropping them because they are outside the capability catalogue. HTML list boundaries and common duties, candidate-criteria, benefits and employer/location headings are recognised. Mixed training-benefit text retains stated candidate skills while excluding the benefit as course-administration evidence. Qualification conditions retain grades, subjects and equivalence wording. Manual items remain unknown: they are not automatically classified as absent, inferred credentials, line management or specialist ownership.

Use Requirement extraction coverage and its expandable source-unit table to inspect how each supplied passage was treated, including exclusions and unresolved context. Repeated category occurrences retain all source references without multiplying the same manual-facet weight. Counts describe source accounting, not guaranteed semantic completeness. Generic overlap can no longer hide the newly retained manual conditions; many vacancies will therefore be Not assessable until their requirements can be checked. This release improves extraction transparency; it does not add automatic evidence matching for the retained manual categories.

## Daily human review (5.5.1)

Use Fit Calibration (V5.5), supply the full original advert and Evaluate evidence. Check the explicit checkbox linking the paste to a selected provider listing only when they are the same vacancy. Published requirements and inferred sector context are distinct; the sector selector is advisory.

For items not evidenced automatically, the checklist records your own confirmation; it does not invent a CV quotation. Unknown remains distinct from an explicit “I do not meet this”. Critical credentials and existing clearance need separate verification even if other essentials reach the threshold.

After evaluating, use Your review and improvement cycle. Choose Apply/Skip/Investigate, say whether the evaluation is reasonable/too positive/too negative/uncertain, select the main reason, optionally identify a requirement and explain the correction. Save my review stores the versioned snapshot in this browser. A personal preference is not treated as an engine mistake, and choosing Apply does not send an application. Live-result decision buttons lead to this detailed review path.

At the end of your chosen period, use the 7/30/90-day summary and Export reviews and improvement report. Export regularly for backup. Return the report for case inspection and a proposed versioned correction; rules change only after regression checks and owner approval. No automatic fine-tuning or background scheduled changes occur. The ledger/export excludes CV text and CV quotations, but includes advert text and the notes you enter.

## Strict shortlist and classification review (5.5.2)

Live vacancies, the calibration dropdown and intelligence comparisons now apply the same conservative completeness filter: published closing date (not expired), published numeric salary rather than a provider estimate, specific workplace, permanent contract or stated FTC duration, detailed source text and HTTPS advert URL. Hourly/part-time pay also requires weekly hours. Search excerpts often omit these facts: zero visible results is therefore a valid outcome, not proof that the market has no jobs. The app does not fetch missing source pages automatically. Paste a complete original advert in Fit Calibration instead; do not invent a deadline or copy the posting date into closing date.

Use **Review requirements**, inspect every priority dropdown, then tick **I checked the classifications against the original source** and select **Evaluate evidence**. Optional **Paste essential criteria here** / **Paste desirable criteria here** fields accept exact excerpts contained in the full advert. They provide a starting classification; the per-requirement dropdown is the final user correction. Generic headings such as About you and Skills and experience remain unspecified. The same detected category in essential and desirable sections is retained separately. General duties do not enter the desirable threshold denominator. No confirmed essential criteria means no essential-fit score or application recommendation. Classification is not evidence that the candidate meets the criterion.

Source text remains unchanged. User-transcribed location, closing date, contract duration and hours are labelled as such, not independently verified. Corrections, original classifications and SHA-256 provenance survive feedback export; CV text does not. Changing inputs invalidates the prior evaluation before feedback can be saved. New vacancy actions reset supplemental fields. The underlying engine retains legacy defaults for archived comparison runs; all current UI evaluation/search paths explicitly activate the strict policies.

## Retrieve sources before filtering (5.5.3)

Search Adzuna now discovers up to 20 results, then automatically attempts the linked original pages (three concurrent requests, ten-second limit per source). The strict completeness filter runs after retrieval. The screen separates **ready for review**, **original sources retrieved**, and **not verified**; unavailable retrieval is never described as proof that the actual advert lacks facts.

Retrieval supports a bounded allowlist of public employer/recruiter/ATS HTML domains and ordinary HTTP/HTML redirects. Unsupported domains, PDF or JavaScript-only pages, access restrictions, unresolved Adzuna landing pages and ambiguous role identities remain unverified and outside the shortlist. This is partial automatic coverage, not an all-web crawler. The original advert can still be supplied manually. Source retrieval is not a guarantee of hiring activity or semantic completeness.

Published JobPosting salary, location and validThrough are used where available. datePosted is not a deadline. Indexed salary/location/contract facts are cleared when assessing the retrieved source, so they cannot silently fill missing original evidence. A fetched description is not automatically declared a complete advert: inspect it and confirm in calibration before scoring. Exact text and decoded HTML SHA-256 hashes, requested/final URLs, redirect chain, retrieval time and extraction method are retained. No CV is transmitted during retrieval. Search tickets expire after 15 minutes; source caching is bounded and lasts at most ten minutes. Tests and QA use synthetic pages and no live paid API calls.

## Current search policy: seven-day discovery (5.5.4 — supersedes 5.5.2/5.5.3 visibility gates)

Search shows provider listings published between the instant the user starts the search and exactly seven days before that instant, including all of the last 24 hours. The anchor remains fixed when loading more pages. Keywords, search area and radius still define the requested search; there is no salary, contract, source-retrieval or completeness eligibility gate on visibility. The search salary field and provider salary filter have been removed. Personal salary/FTC preferences remain in calibration, where unknown facts are checks, not reasons to hide a discovery result.

The Adzuna request uses max_days_old=7, newest-first ordering and user-initiated pages of 20. **Load next 20 results** appends and deduplicates further provider pages; it does not claim the first page covers every available vacancy. No automatic original-source requests are made during discovery. The optional source-verification implementation is retained but is not a prerequisite or invoked by this flow.

Provider `created` timestamps with explicit time zones determine visibility and are shown in Europe/London time. Missing or invalid timestamps cannot establish the seven-day window and are counted separately. An explicitly supplied NEW badge is retained and shown as a provider label. NEW in ordinary description prose is not a freshness badge; no badge is invented. NEW never overrides an old/future/missing timestamp, and neither the badge nor the provider timestamp independently verifies original publication or excludes reposting.

Cards and the calibration dropdown now include recent listings even when salary, specific workplace, contract, closing date or source verification are absent. Missing facts are labelled Not supplied. Summary-only cards have no numeric fit score. Both CV and no-CV paths provide Assess full advert; classification review and full original text remain necessary before scoring. Source publication time, badge and search snapshot anchor are included in saved review provenance; previous review records remain intact.
