# V5.5.1-r2 — confirmed professional profile

One profile screen replaces the old demo profile/settings navigation and separate Semantic AI tab. The CV remains a single source field with existing local file parsing. AI analysis is a user-triggered, separately consented paid request using the existing server-side key. AI_PROFILE_APPROVED enables profile requests only; general paid matching remains disabled. No automatic CV transmission, retry or recurring analysis.

AI proposes core/secondary/additional capabilities, dated roles and scope, with exact source quotations. Every retained finding needs explicit human confirmation. Unverifiable quotations cannot be confirmed. Facts, AI summaries, uncertainties, and search preferences remain distinct. No numerical proficiency, market salary or years-to-seniority claim is invented. Contact patterns and configured names are masked; this is not anonymisation.

Confirmed profile and original CV are stored locally. CV SHA-256, response SHA-256, model, dictionary version, analysis/confirmation times and revision are retained. CV changes invalidate confirmation. Backups contain professional quotations; import requires matching source CV and fresh review. Existing review ledgers are preserved.

Confirmed role families supply selectable title variants; search location, radius and salary transfer into Live and salary/contract thresholds into calibration. Relevance checks use role title/family, exclude clearly manual work and explicit people-management remits when requested. Unknown sectors receive no penalty; text-based sector signals are unverified and preferences reorder, never certify employer identity. Only the first 20 provider results are screened per search; this is not exhaustive coverage.

A bounded local dictionary normalises shared concepts on both sides for preliminary relevance, retaining exact CV quotations. Coordination/delivery and budget support/ownership remain separate. Shared concepts are not proof of specialist tool equivalence or suitability. Full scoring remains the V5.5.1 engine, using confirmed quotations; unsupported conclusions are not silently filled by AI.

Seven-day discovery remains. Summaries show preliminary comparison, not an automatic Apply. Unresolved full-advert evaluations show checks and leave Apply / Discard-Skip to the user. No application submission or automatic tuning.

Validation: offline regression/integration checks and Cloud Browser flow with synthetic AI responses and synthetic listings. Tested review/confirmation, reload, search transfer, warehouse/developer rejection and changed-CV invalidation. No personal CV used, no real paid request or real Adzuna search made in these checks. API account/model connectivity is not proven by mocks.
